# Projeto Rick and Morty

Aplicativo desenvolvido em React Native/Expo como projeto acadêmico.

## Funcionalidades

- Consumo da Rick and Morty API
- Lista de personagens
- Imagens dos personagens
- Pesquisa por nome
- Filtro por status
- Ordenação A-Z e Z-A
- Visualização de detalhes
- Indicador de carregamento
- Tratamento de erro

## API utilizada

Rick and Morty API:
https://rickandmortyapi.com/api/character

## Arquivo principal

O código do aplicativo está no arquivo `App.js`.
